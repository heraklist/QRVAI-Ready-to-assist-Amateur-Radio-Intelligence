## Decisions and rulings

- **Ruling R1 — Native dependency bootstrap:** started with Node 22's `node:test` / TypeScript strip-types to record an actual dependency-free Task 1 RED before pinning SDK dependencies. Both Node native tests and Cloudflare Workerd Vitest tests are retained. This differs from the plan's initial Vitest-only phrasing, but adds negative coverage instead of weakening it.
- **Ruling R2 — SDK v2 compatibility:** pinned `@modelcontextprotocol/server@2.3.1`, `agents@0.28.1`, `zod@4.2.1`, Worker test plugin `@cloudflare/vitest-plugin@1.4.2`, `vitest@4.1.0`, `wrangler@4.135.0` with exact npm lock; no invented compatible versions. Temporary package-lock bootstrap workflows with write permissions were **removed** and are not present in final tree.
- **Ruling R3 — Authless safety:** public endpoint supports only one deterministic read-only tool; unknown input keys rejected with strict Zod schema, real MCP transport tested; no personal logbook/callsign/QTH/device/third-party network usage. Cloudflare quota abuse remains a residual risk for later owner-authorized staging.
- **Ruling R4 — Release separation:** the example report is explicitly `NOT_EXECUTED`; `scripts/check-release-gates.mjs` checks documentary fields offline. Passing documentation checks could never independently certify external URL validity or host behavior; separate release human verification remains necessary.
- **Ruling R5 — Source governance:** `npm run build:check` is `wrangler deploy --dry-run` on the GitHub runner only, with no Cloudflare API credentials. The 12-file QRVAI V0 Skills source is unchanged. Draft PR #8 remains a separate unmerged design/plan PR; Draft PR #9 does not silently merge or package it.
