# SS-B12-3 — Backup Scenario

**Owner:** SK-B12
**Responsibility:** compare backup topology and resilience under loss scenarios
**Required input:** Paper-only backup load priorities, estimated available usable Wh, switch/fallback alternatives, finite simulated outage duration and safe professional constraints.
**Procedure:** Compare conceptual parallel battery/UPS/solar availability and load-shedding without modifying wiring or switching physical equipment. Simulated scenario only; if photovoltaic input missing, mark energy yield UNVERIFIED, not a live forecast. Document single-point failure and missing redundancy.
**Output:** Exercise-only autonomy table, backup choices and assumptions for qualified review. No real dispatch/operational command.
**Error/stop:** No automatic station switching, mains repairs, battery-pack rewiring, solar/electrical installation design certificate or real guaranteed resilience.

**Status:** IDEAL_MODEL, not physical measurement, battery certification or power installation approval.
